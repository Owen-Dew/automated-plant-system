# automated-plant-system
My project is an automated plant growing system which has been designed and built using a Raspberry Pi Pico and MicroPython.

The system has been designed to monitor the conditions required to best grow and maintain a basil plant through automatically controlling watering and ventilation. The temperature and humidity are measured using a BME280 sensor, while a capacitive soil moisture sensor is used to determine when the plant requires watering.

A 5V water pump is controlled using a relay which allows the pico to automatically irrigate the plant. A separate relay channel has been used to control a small ventilation fan which is dependant on the conditions within the closed enclosure.

The final system is housed inside an enclosure to allow separation of electronic hardware and water for safety.

# Objectives

The main objectives of the project are to:

・ Monitor temperature and humidity around the plant
・ Monitor soil moisture
・ Automatically water the plant when the soil becomes sufficiently dry
・ Program the system using MicroPython
・ Finalise the project and package into a compact enclosure

# Hardware

The main components used in the project are as follows:

・ Raspberry Pi Pico
・ BME280 temperature, pressure and humidity sensor
・  Capacative soil moisture sensor
・ 5V Water pump (peristaltic)
・ 5V Ventilation fan 
・ Multi-channel relay module
・ 5V Power supply
・ 1N4007 Flyback Diode

# Software

The system is programmed using MicroPython on the Raspberry Pi Pico.

The Pico is able to communicate to the BME28- using I2C and reads the soil moisture sensor using an analog input. relay outputs are then used to control the water pump and ventilation fan. 

The software has been developed and tested and specific increments, with individual sensors and outputs tested before being integrated into the complete system.

# System Design

The system is made of many subsystems which are interconnected. The BME280 monitors the temperature and humidity inside the plant enclosure while the capacitive soil moisture sensor monitors the moisture level of the soil and acts accordingly.

The Raspberry Pi processes these measurements and controls the relay module. One relay channel controls the water pump when the soil moisture falls below the set value which has been calculated, the Pi activates the relay and supplies power to the pump. A second relay channel controls the ventilation fan, this is controlled according to temperature and humidity inside the enclosure.

# Development and Testing

The project was developed by testing each component individually before combining together. The BME280 was tested using I2C communication and its address was 0x77. First testing for this sensor required troubleshooting communication errors and ensuring the temperature and humidity values were accurate. The soil moisture sensors was tested at different moisture levels which allowed a suitable moisture level for dry and wet soil to be obtained. These values were then used to determine the threshold for automatic watering.

The relay and water pump were then tested. During initial testing, the relay indicator changed state but the pump did not operate. After testing thoroughly, the issue was identified to be the Pico control pin so the pump relay was moved to a different GPIO pin which solved the issue.

While integrating the system, a communication problem kept arising between the BME280 and the pump when operated through the relay. The BME280 produced an I2C communication error while the pump was operating. Disconnecting the pump caused the BME280 to return to stable operation.

This indicated that the pump motor was introducing electrical interference into the system. Therefore a 1N4007 flyback diode was installed across the pump terminals. The diode then provided a path for the voltage generated by the motor when it was switched off which reduced the electrical disturbance produced by the inductive load. 

After installation, the system operated without the previous BME280 communication errors.
